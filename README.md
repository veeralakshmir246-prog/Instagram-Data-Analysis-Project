# Instagram Reach & Engagement Analytics

An Exploratory Data Analysis (EDA) mini project developed to analyze and visualize Instagram engagement trends using Python.

## 🚀 Project Overview
This project focuses on evaluating how different types of Instagram posts (Photos, Reels, Carousels) perform in terms of reach (Impressions) and user interactions (Likes & Comments). It provides actionable data-driven insights to help content creators and businesses optimize their social media strategy.

## 🛠️ Tools & Technologies Used
* **Language:** Python
* **Libraries:** Pandas, Matplotlib, Seaborn
* **Environment:** Google Colab / Jupyter Notebook

## 📊 Key Analysis & Insights
1. **Reach Analysis:** Analyzed how `Impressions` vary dynamically across Photos, Reels, and Carousels.
2. **Engagement Comparison:** Visualized `Likes` and `Comments` side-by-side using Bar Charts to find the most engaging post format.
3. **Relationship Mapping:** Built a Scatter Plot to explore the correlation between `Impressions` and `Likes`, establishing a clear linear growth pattern.

## 📁 Repository Contents
* `instagram_analysis.py`: The core Python source code containing data preparation and visualization scripts.
* `Instagram_Full_Data_Analysis_Project.pdf`: A complete, presentation-ready PDF report containing all compiled charts.

## 📈 How to Run
1. Open Google Colab or Jupyter Notebook.
2. Run the code inside `instagram_analysis.py` to regenerate the charts dynamically.
